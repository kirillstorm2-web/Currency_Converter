# Currency Converter

## Author
Ivan Ivanov

## Description
GUI application for converting currencies using ExchangeRate API.

## Features
- Currency conversion
- History tracking
- JSON storage

## How to run
1. Install dependencies:
   pip install requests

2. Run:
   python main.py

## API Key
1. Register at https://www.exchangerate-api.com/
2. Replace YOUR_API_KEY in code
